Decision-making under uncertainty

Build a payoff table, compare four decision criteria, and follow a staged-filtering process. Change any value to update the analysis automatically.

1. Decision problem

Edit the alternatives, states of nature, payoffs, and probabilities. Payoffs are assumed to be values to maximize.

Use numeric payoffs. Probabilities must be between 0 and 1 and add up to 1 for EMV/Bayes.

2. Decision criteria

The recommended alternative(s) and criterion value are recalculated from the payoff table.

3. Staged filtering

This transparent three-stage filter keeps alternatives that meet each decision rule: first the best worst-case payoff (Maximin), then the best expected value (EMV) among survivors, then the best best-case payoff (Maximax). Ties remain in the process.
